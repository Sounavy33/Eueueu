Atalhos

Manual rápido

Branch

É o ramo ou linha de trabalho do projeto. Você usa para separar versões e mudanças.

Commit

É um ponto salvo com uma alteração. Pense como um checkpoint do código.

Log

É o histórico das alterações. Mostra quando e quem mudou cada coisa.

Pull request

É um pedido para revisar e juntar alterações antes de entrar no projeto principal.

Actions

São workflows e automações. Ações podem testar, compilar ou rodar etapas do projeto.

Configuração

É a área de ajustes do repositório, permissões, proteção e regras do projeto.
